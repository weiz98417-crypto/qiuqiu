# MVP Extras — 用户偏好记忆 + 极简身份

## 目标

实现 CEO 审查新增的 3 个体验功能，让 MVP 不只是"能看"而是"好用"。

## 范围

| 模块 | 内容 |
|------|------|
| 极简身份 | 昵称 + 主队设置，无需注册登录，本地存储 |
| 用户偏好记忆 | 主队/昵称/话痨偏好本地持久化，影响球球行为 |
| ~~分享卡片~~ | 移至 v1.1（核心体验验证通过后再做增长杠杆） |

## 不在范围

- 用户注册/登录系统（Phase 4）
- 云端偏好同步（Phase 4）
- 社交媒体深度集成（Phase 4）
- 分享数据统计（Phase 4）

## 依赖

- `watch-integration` — 需要端到端流程跑通

## 里程碑

- [ ] 用户可设置昵称 + 主队，无需注册
- [ ] 球球根据用户主队调整行为偏向
