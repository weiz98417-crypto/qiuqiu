# Resilience — 异常处理 + 内容质量

## 目标

面对网络波动、API 故障、数据延迟等异常场景，球球优雅降级而非崩溃。同时扩充句式池减少重复。

## 范围

| 模块 | 内容 |
|------|------|
| 网络恢复 | WebSocket 断连自动重连（指数退避 1s→2s→4s→8s） |
| API 降级 | LLM Deepseek→Ollama→模板 自动切换 |
| 数据延迟 | 数据源断连 >15s 提示用户，>60s 降级为"等待中" |
| 音频异常 | 全静音/超短/超长音频检测，降级为文字气泡 |
| 句式池扩充 | 每种事件类型 10+ 种表达变体 |
| 兜底模板 | 覆盖所有 12 种事件类型 |

## 不在范围

- 多比赛并发恢复（Phase 4）
- 监控告警（Phase 4）

## 依赖

- `watch-integration` — 异常场景主流程
- `ai-pipeline` — 降级链路

## 里程碑

- [ ] 网络中断后 10s 内自动重连
- [ ] API 降级切换 < 500ms
- [ ] 句式池 12 种事件 × 10+ 变体
- [ ] 兜底模板覆盖 100% 事件类型
