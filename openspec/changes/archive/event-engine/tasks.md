# Event Engine 任务拆解

### T1: 标准化事件定义
- 定义 `StandardEvent` 结构体
- 事件类型常量（goal/shot/card/...）
- 从 api-sports.io 原始格式 → 标准化格式的转换函数
- **验证**: 单测覆盖所有事件类型的解析

### T2: 数据源轮询器
- api-sports.io HTTP client 封装
- 每 3s 轮询 `/fixtures/events`
- 差分检测（对比 lastEventID）
- 指数退避重连（断连 >5s 时）
- **验证**: 对真实比赛跑 5 分钟，确认事件不丢

### T3: 去重 + 节流
- Redis 滑动窗口去重
- 按事件类型的节流间隔配置
- **验证**: 模拟同一事件 ×3 → 只通过 1 条；10s 内 3 次射门 → 只通过 1 条

### T4: 优先级队列 + 冷却
- P0/P1/P2/P3 优先级常量
- 优先队列实现
- 冷却检查（8s，P0 可跳过）
- **验证**: 同时到达射门+进球 → 先进球后射门；冷却中 P0 立即通过

### T5: 上下文增强
- `EnrichContext()` 实现
- 帽子戏法/绝杀/扳平/首开纪录检测
- 时间语境（开局/中段/尾声）
- **验证**: 帽子戏法场景正确标记；85分钟后进球标记为"绝杀"
