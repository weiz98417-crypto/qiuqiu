# Talkativeness Control — 话痨程度调节

## 目标

让用户控制球球的说话频率，适应不同观赛场景：深夜安静看球、日常标准陪看、聚会热闹氛围。

## 范围

| 模块 | 内容 |
|------|------|
| 三档调节 | 安静 / 标准 / 活跃 |
| 参数化配置 | 每档独立的优先级过滤、冷却时间、事件间隔倍率 |
| 主动说话 | 活跃模式下用户沉默3分钟主动找话说 |
| UI 三段滑块 | 观赛页随时切换，球球语音确认 |
| 偏好持久化 | 用户选择存储到本地，下次观赛默认使用 |

## 不在范围

- 基于比赛节奏的自动动态调节（Phase 3）
- 服务端偏好同步（Phase 4）

## 依赖

- `event-engine` — 事件节流参数由话痨档位驱动

## 里程碑

- [ ] 安静模式 90 分钟说话 < 15 次
- [ ] 活跃模式用户沉默 3 分钟后主动说话
- [ ] 切换档位 < 1s 生效
- [ ] 偏好跨会话持久化
