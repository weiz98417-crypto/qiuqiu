# Resilience 任务拆解

### T1: WebSocket 自动重连
- 客户端指数退避重连（1s→2s→4s→8s，最大 5 次）
- 重连期间 Live2D 显示"正在重连..."
- 用户语音本地缓存，重连后补发
- **验证**: 断网 5s → 自动重连成功 → 语音继续

### T2: API 降级串联
- LLM: Deepseek → Ollama → 模板（<500ms 切换）
- TTS: ElevenLabs → 文字气泡
- 降级事件埋点（error_type, fallback_used）
- **验证**: 模拟各层故障 → 确认降级生效

### T3: 数据源断连恢复
- 15s/30s/60s 分级检测
- Live2D 表情 + 文字提示
- 重连后恢复陪看
- **验证**: 断网 20s → 提示出现 → 恢复后继续

### T4: 句式池 + 兜底模板
- 12 种事件 × 10+ 变体句式池
- 兜底模板覆盖全部事件类型
- **验证**: 模拟 LLM 不可用 → 兜底输出自然不机械
