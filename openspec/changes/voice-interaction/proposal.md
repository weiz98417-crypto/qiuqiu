# Voice Interaction — 用户语音交互 + ASR + 打断

## 目标

实现球球和用户之间的双向语音对话。用户说话时球球能听懂并回应，用户插话时球球立刻闭嘴倾听。

## 范围

| 模块 | 内容 |
|------|------|
| ASR 语音识别 | Whisper API 流式识别，中文为主+中英混合球员名 |
| VAD 语音检测 | 客户端静音检测（-26dB/300ms最短/800ms静音超时/15s最大） |
| 按住说话 | 按住🎤说话，松开发送 |
| 自由对话 | 点🎤进入持续收音，VAD自动断句 |
| 打断机制 | 用户说话→球球100ms淡出静音→Live2D切listening |
| 对话上下文 | 最近3轮用户发言+球球回复+中间事件 |
| 意图识别 | 提问/评论/指令/闲聊 4类，路由到不同回复策略 |
| 文字降级 | 语音不可用时文字输入替代 |

## 不在范围

- 名人语音彩蛋（Phase 3，需外部授权）
- 自部署 SenseVoice（Phase 3 性能优化）
- 多模态输入扩展

## 依赖

- `ai-pipeline` — LLM + TTS
- `event-engine` — 比赛上下文
- `watch-integration` — 会话管理

## 里程碑

- [ ] 安静环境下 ASR 准确率 > 95%
- [ ] 用户说话到球球回复 < 2s
- [ ] 打断响应（球球停止）< 150ms
- [ ] 连续 20 轮对话不掉上下文
- [ ] 文字输入降级可用
