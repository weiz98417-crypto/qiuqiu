# Companion Explorer - 用户主动沟通探索器

## Why

QiuQiu 现在已经能接收导演台事件，也能做基础主动回应，但还没有把“用户主动问比赛”这条线产品化成一个稳定闭环。用户问比分、助攻、刚刚发生了什么、某个球员有没有进球时，球球需要先查比赛记忆，再决定如何回答，而不是直接把问题交给 LLM 自由发挥。

## What Changes

- 引入一个面向用户主动沟通的 companion explorer 流程，统一处理意图识别、记忆检索、回复生成和 trace 记录。
- 把比赛事实查询和陪聊表达拆开。
- 支持以下核心问法：
  - 当前比分和比赛时间
  - 刚才谁助攻 / 谁参与了进球
  - 某个球员刚才是否进球或参与事件
  - 用户闲聊、吐槽、情绪反馈
  - 用户要求少说一点、安静一点之类的控制指令
- 记录每次回答的 intent、工具调用、命中的事件、最终输出和耗时。

## Non-goals

- 不在这个 change 里引入复杂自治 agent。
- 不在这个 change 里做 pgvector 语义检索。
- 不在这个 change 里重做导演台 UI。
- 不在这个 change 里让模型自行编造未录入的比赛事实。

## Success Criteria

- 用户问“现在几比几？”时，球球能稳定从比赛记忆返回比分。
- 用户问“刚才谁助攻？”时，球球能从事件参与人中返回助攻和策动者。
- 用户问“穆西亚拉刚才进球了吗？”时，如果没有对应记录，球球会明确说没有看到，而不是猜测。
- 所有主动回复都能落 trace。
- 纠正过的事件不会继续出现在 active snapshot 答案里。
