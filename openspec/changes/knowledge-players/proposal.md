# Knowledge Players: 球队与球员档案

## Why

球队/球员档案是知识域最高频的问句（"姆巴佩现在哪个队""皇马队长是谁"），knowledge-rag 的检索/意图基建全部现成，唯一缺口是原料。AnySearch 技能已装好验收（检索 + 整页抽取实测通过），原料通道就绪——ADR-0017 的"策展于 repo"不排斥检索当原料，只要求落库条目有出处、可溯源。

## What Changes

- AnySearch 检索 + `extract` 整页抽取扒料（官网/维基/百科交叉确认）→ 策展 **15–20 条精选档案**：豪门球队（皇马/巴萨/曼联/曼城/拜仁/利物浦/阿森纳/尤文/国米/米兰/大巴黎/切尔西）+ 顶星球员，落 `backend/knowledge/players/*.yaml`。
- 条目以**慢变字段为主**（成立年份、主场、荣誉史、国籍、位置、生涯里程碑、技术风格）；快变字段（现属俱乐部、队长）标 `effective_at`（"截至 2026 夏窗"）。
- ADR-0017 补后果条款：**转会窗复查制度**（每年 7 月/1 月两窗各复查一次快变字段）；未来接 data-provider-lite-bridge 权威源后替换策展。
- 检索天然支持：球员名/队名即 topics，关键词+向量双路零改动。

## User Stories

1. As a 球迷, I want 问"姆巴佩哪个队""伯纳乌能坐多少人"得到准确回答, so that 球球在比赛之外也是聊球的对象。

## Non-goals

- 全量数据库（只做大概率被问到的精选集——规模纪律）。
- 实时数据（伤病/身价等快变时效信息不进策展条目）。
- 实时性替代方案（data-provider 源后续替换）。

## Success Criteria

- 全量 go test + eval 绿；新条目检索命中（关键词与换说法双路）有单测。
- 每条条目带 source（可点开验证）与 effective_at。
