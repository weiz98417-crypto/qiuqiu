# 12 — 表情与动作触发系统

> 所属阶段：Phase 2 · 依赖：07-Live2D角色展示、03-事件处理引擎 · 优先级：P1

---

## 1. 概述

表情与动作触发系统是球球"情绪表达"的调度中心。它根据比赛事件、对话内容和上下文，决定球球的表情状态并驱动Live2D动画切换。

---

## 2. 表情状态全集

### 2.1 基础状态

| 状态ID | 名称 | 描述 | 优先级 |
|--------|------|------|--------|
| idle | 待机 | 轻微呼吸、偶尔眨眼 | 最低 |
| listening | 倾听 | 头微倾、眼睛稍大 | 中 |
| speaking | 说话 | 嘴型同步（叠加于其他状态之上）| 高 |

### 2.2 情绪状态

| 状态ID | 名称 | 面部表现 | 身体表现 |
|--------|------|---------|---------|
| excited | 兴奋 | 眼睛张大、嘴角上扬、眉毛上抬 | 身体前倾、微微晃动 |
| nervous | 紧张 | 眼睛略大、嘴唇微抿 | 身体收紧、拳头微握 |
| regret | 遗憾 | 眉毛下垂、嘴角下弯 | 叹气动作、头微低 |
| tease | 吐槽 | 一侧嘴角上扬、眉毛微挑 | 头微侧 |
| surprised | 惊讶 | 眼睛睁大、嘴巴微张 | 身体后仰 |
| happy | 开心 | 眯眼笑、嘴角上扬 | 轻微点头 |
| confused | 疑惑 | 歪头、眉毛微皱 | 头微倾 |

### 2.3 状态优先级

当多个状态同时触发时，按优先级决策：

```
speaking (叠加) > surprised > excited > nervous > tease > regret > happy > confused > listening > idle
```

## 4. 表情过渡系统

### 4.1 过渡规则

- 不允许硬切（表情突变），所有切换通过Live2D Blend过渡
- 过渡时间 100-500ms，取决于两个状态的差异
- 表情叠加：speaking可与任何情绪状态叠加

### 4.2 过渡时间矩阵（ms）

```
           → excited nervous regret tease happy
idle          300     250     250   200   200
excited        -      200     300   300   200
nervous       200      -      200   200   200
regret        300     200      -    200   300
tease         300     200     200    -    200
happy         200     200     300   200    -
```

### 4.3 表情强度衰减

表情不会永远持续，会自然衰减回idle：

```python
def decay_expression(current, target_idle, elapsed_ms):
    """表情强度随时间衰减"""
    decay_rate = 0.3  # 每秒衰减30%
    intensity = current.intensity * (1 - decay_rate * elapsed_ms / 1000)
    if intensity < 0.1:
        return target_idle
    return blend(current, target_idle, intensity)
```

## 6. 避免"表情抽搐"

- 同一表情最短持续时间：1s
- 短时间内多次表情切换：合并为最强烈的
- 事件间隔 < 2s：只响应优先级更高的

```python
def should_update_expression(new_expr):
    now = time.now()
    if now - last_expr_change < 1.0:  # 1秒内不切换
        if new_expr.priority <= current_expr.priority:
            return False  # 优先级不更高则忽略
    return True
```

## 7. 与TTS的联动

### 7.1 表情驱动TTS参数

| 表情 | TTS情绪参数 |
|------|-----------|
| excited | speed+15%, pitch+10% |
| nervous | speed+5%, pitch-5% |
| regret | speed-10%, pitch-10% |
| tease | speed+10%, pitch+5% |
| happy | speed+5%, pitch+5% |
| normal | 默认 |

### 7.2 语音内容 ↔ 表情细化

LLM返回的文本包含了expression标记，但如果TTS语音中有明显的情绪词（"哇！""哎..."），可以微调表情强度。
