## 1. 语音数据隐私

### 1.1 ASR录音处理

```
用户说话 → 客户端录音(PCM) → TLS加密传输 → 服务端ASR实时转写
                                              │
                                              ▼
                                         转写完成即丢弃
                                         PCM数据不做持久化存储
                                         不用于模型训练
```

| 原则 | 措施 |
|------|------|
| 最小化收集 | 仅采集ASR转写所需的语音数据 |
| 即时丢弃 | 转写完成后立即删除原始PCM |
| 传输加密 | WebSocket over TLS 1.3 |
| 用户告知 | 首次使用麦克风时明确告知"语音数据仅用于实时转写，不保存" |
| 合规 | 参照《个人信息保护法》对生物特征（声纹）数据的处理要求 |

### 1.2 对话内容存储

| 数据类型 | 存储策略 | 保留期 |
|---------|---------|--------|
| AI生成文本 | 存储（用于句式去重和上下文） | 会话期间 |
| 用户转写文本 | 存储（用于上下文理解） | 会话期间 |
| TTS音频 | 不存储（实时流式下发） | 不适用 |
| 会话摘要 | 可选存储（用于偏好学习） | 用户可控 |

## 2. LLM安全

### 2.1 Prompt注入防护

```
用户输入处理流程：

用户ASR转写文本
    │
    ▼
┌──────────────────────────────┐
│  输入隔离层                    │
│  用户输入作为 data 字段注入     │
│  不与 system prompt 拼接       │
│  添加角色前缀标记：             │
│  [用户说]：{转写文本}           │
└──────────────────────────────┘
    │
    ▼
送入LLM（system prompt不可被用户修改）
```

**防护规则：**
- 用户输入始终在 `[用户说]：` 标签内，不与system prompt合并
- LLM调用前检查用户输入是否包含"忽略之前指令"、"你是"、"system:"等注入尝试模式
- 若检测到注入尝试，标记为 `error_type=prompt_injection_attempt`，仍正常处理但不改变system行为

### 2.2 输出安全过滤

详见文档09第6.8节"内容安全输出过滤"：
- 关键词黑名单（脏话/政治/宗教/种族/赌博）
- 绝对化预测过滤（"必赢"→"有很大优势"）
- 安全底线失败 → 静默丢弃，重试生成

## 3. API安全

### 3.1 接口认证

| 接口 | 认证方式 | 说明 |
|------|---------|------|
| 客户端 → 服务端 WebSocket | Token（会话建立时签发） | 短期有效，过期刷新 |
| 内部服务间 NATS | mTLS | 服务间相互验证 |
| LLM/TTS/ASR API | API Key | 环境变量注入，密钥轮换 |

### 3.2 WebSocket消息校验

```
客户端 → 服务端消息：
  ✅ 允许：{ type: "voice", data: <PCM> }
  ✅ 允许：{ type: "text", message: <string> }
  ✅ 允许：{ type: "talkativeness", level: "quiet"|"normal"|"active" }
  ❌ 禁止：{ type: "event", ... }（客户端不可发布比赛事件）
  ❌ 禁止：{ type: "expression", ... }（客户端不可控制角色表情）

服务端 → 客户端消息：
  ✅ 允许：{ type: "audio", data: <PCM>, expression: <string> }
  ✅ 允许：{ type: "event", ... }
  ✅ 允许：{ type: "expression", state: <string> }
```

服务端必须拒绝所有不符合消息类型白名单的客户端消息。

## 4. 数据存储安全

### 4.1 敏感数据分类

| 数据 | 分类 | 存储位置 | 加密 |
|------|------|---------|------|
| 用户昵称 | PII | PostgreSQL | 传输加密 |
| 用户主队偏好 | 偏好数据 | PostgreSQL/LocalStorage | 传输加密 |
| 会话记录 | 行为数据 | PostgreSQL | 传输加密 |
| ASR原始PCM | 生物特征 | 不存储 | N/A |
| API Key | 密钥 | 环境变量/K8s Secret | at-rest加密 |

### 4.2 用户删除权

- 用户可随时清除偏好数据（主队/历史记录）
- 删除操作在24小时内完成并确认
- 无云端账号时，数据仅存本地，卸载即删除

## 5. 名人语音授权合规

> ⚠️ 本项为CEO审查新增的SELECTIVE EXPANSION功能

### 5.1 授权要求

- 任何名人/网红语音克隆必须在**书面授权协议签署后**才能集成
- 授权协议须明确：使用范围（仅球球App内）、使用期限、分成条款（如有）
- 在App中标注"本音色由[姓名]授权使用"

### 5.2 技术隔离

- 名人语音模型独立部署，与球球默认音色隔离
- 授权到期后，自动下架该音色，已下载用户切换回默认音色
- 语音克隆素材仅用于训练TTS模型，不另作他用

### 5.3 未授权时的降级

- 若世界杯前未获取授权，该功能自动推迟
- "名人语音彩蛋"功能标记为 `feature_flag: celebrity_voice`，可随时关闭

## 6. 威胁模型总览

| 威胁 | 概率 | 影响 | 缓解措施 | 状态 |
|------|------|------|---------|------|
| ASR语音数据泄露 | 低 | 高 | PCM不存储，TLS传输 | ✅ 已设计 |
| LLM Prompt注入 | 中 | 中 | 输入隔离+标签包裹 | ✅ 已设计 |
| LLM输出违规内容 | 中 | 高 | 关键词过滤+安全底线检查 | ✅ 已设计 |
| WebSocket消息伪造 | 低 | 中 | 服务端消息类型白名单 | ✅ 已设计 |
| API Key泄露 | 低 | 高 | 环境变量+K8s Secret+轮换 | ✅ 已设计 |
| 名人语音无授权使用 | 中 | 高 | 授权前置+功能开关 | ✅ 已设计 |
| 用户数据泄露 | 低 | 高 | 最小化收集+TLS+删除权 | ✅ 已设计 |
