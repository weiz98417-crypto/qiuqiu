# 06 — ASR语音识别系统

> 所属阶段：Phase 2 · 依赖：无 · 优先级：P1

---

## 1. 概述

ASR（Automatic Speech Recognition）系统负责将用户的语音输入实时转化为文字，使球球能"听懂"用户说话。

核心要求：
- 实时流式识别（边说边识别）
- 支持打断（用户说话时球球停止发声）
- 中文识别准确率 > 95%
- 支持中英混合（球员名、球队名）

---

## 2. 模型选型

| 方案 | 延迟 | 准确率 | 中英混合 | 成本 | 推荐 |
|------|------|--------|---------|------|------|
| Whisper API | ~1s | 高 | 支持 | $0.006/min | MVP首选 |
| SenseVoice（阿里） | ~300ms | 极高 | 支持 | 自部署（Apache 2.0） | 生产推荐 |
| Azure Speech | ~400ms | 高 | 支持 | $1/hour | 备选 |
| Deepgram | ~300ms | 高 | 支持 | $0.005/min | 备选 |

> FunASR 已移除 — 2025年后进入维护模式，阿里重心已转向 SenseVoice。
> 定价为2026年5月快照，实际以各API官网最新价格为准。

**策略**：MVP用Whisper API快速验证，生产自部署SenseVoice降低延迟和成本。

## 3. 实时流式架构

```
用户麦克风 → PCM音频流 → WebSocket → ASR服务
                  ↓
         VAD（Voice Activity Detection）
         → 检测到说话开始 → 发送音频帧
         → 检测到静音(>800ms) → 标记句子结束
                  ↓
         识别结果回调 → 发送到对话系统
```

### 3.1 VAD 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 静音阈值 | -26dB | 低于此值视为静音 |
| 最短说话时长 | 300ms | 避免误触发 |
| 静音超时 | 800ms | 静音多久视为说话结束 |
| 最大说话时长 | 15s | 超长自动截断 |
| 采样率 | 16kHz | 单声道 |

### 3.2 打断检测

```
球球正在说话 ──→ 检测到用户语音活动 ──→ 立即：
  1. 停止当前TTS播放（淡出 100ms）
  2. 停止当前音频流下发
  3. 球球表情切为"倾听"状态
  4. ASR开始接收用户语音
  5. 识别完成后LLM生成回复
```

## 4. 识别上下文增强

利用已知的比赛上下文提升识别准确率：

```python
context_hints = [
    # 当前对阵球队名
    match.home_team.name,      # "皇家马德里"
    match.away_team.name,      # "巴塞罗那"
    # 场上球员名
    *[p.name for p in match.players],  # "姆巴佩", "贝林厄姆"...
    # 足球术语
    "进球", "射门", "越位", "犯规", "点球",
    "换人", "黄牌", "红牌", "VAR",
    # 常见问题
    "会进吗", "谁进的", "比分多少", "还有多久"
]
```

## 5. 意图识别

识别完成后，对用户输入进行快速意图分类：

| 意图 | 示例 | 处理方式 |
|------|------|---------|
| 提问-事实 | "谁进的球？" | 查比赛数据回答 |
| 提问-预测 | "会进吗？" | LLM自由发挥 |
| 评论-兴奋 | "好球！！" | 共鸣回应 |
| 评论-吐槽 | "这都不进..." | 共鸣回应 |
| 闲聊 | "你猜我是谁" | 日常对话 |
| 指令 | "安静点" | 调整话痨档位 |
| 无意义 | "额..." | 忽略 |

## 6. 接口定义

```
流式输入（客户端→服务端）:
WS /ws/asr/{session_id}
  → Binary Frame: PCM音频块 (每帧 20ms)
  → Text Frame: { "type": "speech_end" }

流式输出（服务端→客户端）:
  ← Text Frame: {
      "type": "partial",        // 中间结果
      "text": "这球会",
      "is_final": false
    }
  ← Text Frame: {
      "type": "final",          // 最终结果
      "text": "这球会进吗",
      "is_final": true,
      "intent": "提问-预测",
      "confidence": 0.95
    }
```

## 7. 异常处理

| 场景 | 策略 |
|------|------|
| 背景噪音大 | VAD过滤 + 提示用户靠近麦克风 |
| 说话太轻 | 自动增益调节 |
| 识别为空 | 忽略，不触发回复 |
| 识别置信度低 | 不回复，等待用户重新说话 |
| ASR服务不可用 | 降级通知"球球听不见了，打字聊吧～" |
| 网络延迟 | 本地VAD预判，不等完整识别 |

---

## 8. 隐私设计

- 音频流不落盘，识别完成后立即丢弃
- 用户可查看/删除历史对话记录
- 语音数据不上传第三方（自部署ASR后）

---

## 9. 验证标准

- [ ] 安静环境下识别准确率 > 95%
- [ ] 噪音环境（60dB）识别准确率 > 85%
- [ ] 中英混合（球员名）准确率 > 90%
- [ ] VAD 误触发率 < 5%
- [ ] 打断响应延迟 < 300ms（从用户说话到球球停止）
