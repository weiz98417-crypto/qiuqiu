# 13 — 客户端架构设计

> 所属阶段：Phase 1–3 · 依赖：07-Live2D、09-核心流程 · 优先级：P0

---

## 1. 概述

客户端是用户与球球交互的载体，承载Live2D渲染、音频播放/录制、WebSocket通信和UI交互。

技术栈：**Flutter**（跨平台iOS/Android）

---

## 2. 技术选型

| 组件 | 方案 | 理由 |
|------|------|------|
| 框架 | Flutter 3.x | 跨平台，一套代码 |
| 状态管理 | Riverpod | 类型安全，可测试 |
| 路由 | go_router | Flutter官方推荐 |
| 网络 | web_socket_channel | WebSocket支持 |
| 音频播放 | audioplayers | 流式PCM播放 |
| 音频录制 | record | 支持实时音频流 |
| Live2D | 原生PlatformView封装 | 性能最优 |
| 持久化 | shared_preferences + sqflite | 配置+结构化数据 |

## 5. WebSocket连接管理

### 5.1 连接生命周期

```dart
class WebSocketService {
  WebSocketChannel? _channel;
  Timer? _heartbeatTimer;
  Timer? _reconnectTimer;
  int _reconnectAttempts = 0;

  Future<void> connect(String matchId);
  void _startHeartbeat();
  void _onMessage(dynamic data);
  void _onDisconnect();
  Future<void> _reconnect();
  void sendVoice(Float32List pcmData);
  void disconnect();
}
```

### 5.2 重连策略

```dart
static const _reconnectDelays = [1, 2, 4, 8, 16, 30]; // 秒
static const _maxReconnectAttempts = 6;

Future<void> _reconnect() async {
  if (_reconnectAttempts >= _maxReconnectAttempts) {
    // 放弃重连，提示用户
    return;
  }
  final delay = _reconnectDelays[_reconnectAttempts];
  await Future.delayed(Duration(seconds: delay));
  _reconnectAttempts++;
  await connect(_currentMatchId);
}
```

## 8. 本地缓存与持久化

| 数据 | 存储方式 | TTL |
|------|---------|-----|
| 用户偏好 | shared_preferences | 永久 |
| 最近比赛列表 | sqflite | 1小时 |
| 单场比赛事件 | sqflite | 比赛结束后24h |
| 对话历史 | sqflite | 7天 |
| Live2D模型 | 文件系统 | 更新时替换 |
| 预置音频 | 文件系统 | 更新时替换 |

## 9. 性能指标

| 指标 | 目标 |
|------|------|
