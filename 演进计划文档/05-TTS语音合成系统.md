# 05 — TTS语音合成系统

> 所属阶段：Phase 1 · 依赖：04-LLM对话生成 · 优先级：P0

---

## 1. 概述

TTS（Text-to-Speech）系统负责将LLM生成的文字转化为自然语音，是球球"开口说话"的最后一环。

核心要求：
- 首包延迟 < 800ms
- 音色自然、有亲和力
- 支持情绪语音（兴奋、平静、遗憾等）
- 流式输出，边合成边播放

---

## 2. 模型选型

| 方案 | 延迟 | 情绪支持 | 音色自然度 | 成本 | 推荐 |
|------|------|---------|-----------|------|------|
| ElevenLabs | ~500ms | 强 | 极高 | $5-99/月订阅制 | 生产首选 |
| CosyVoice 2 | ~200ms | 强 | 高 | 自部署（Apache 2.0） | 开发+兜底首选 |
| Fish-Speech 1.5 | ~400ms | 强 | 高 | 自部署 | 音色克隆备选 |

> Edge-TTS 已移除 — 微软浏览器内置非公开API，商业使用有法律风险。
> 定价为2026年5月快照，实际以各API官网最新价格为准。

**策略**：开发用 CosyVoice 2（Apache 2.0开源，免费自部署）→ 生产首选 ElevenLabs（情绪控制强）→ 音色克隆用 Fish-Speech 1.5。

---

## 3. 球球音色定义

| 维度 | 要求 |
|------|------|
| 性别 | 女性 |
| 年龄感 | 20-25 岁 |
| 风格 | 自然、亲切、有一点点俏皮 |
| 语速 | 适中偏快（正常 1.1x） |
| 音调 | 中音偏高 |
| 情绪范围 | 兴奋、平静、遗憾、惊讶、吐槽 |

**参考**：朋友之间聊天的语气 — 不是播音腔、不是客服腔、不是萝莉音。定位是"一个懂球的女生朋友"。

---

## 4. 情绪语音映射

| LLM表情 | TTS情绪参数 | 表现 |
|---------|------------|------|
| excited | 语速+15%、音调+10% | 明显兴奋 |
| nervous | 语速+5%、音调-5% | 略带紧张 |
| normal | 默认参数 | 自然聊天 |
| tease | 语速+10%、音调+5% | 轻快吐槽 |
| regret | 语速-10%、音调-10% | 遗憾感 |

---

## 5. 流式处理流程

```
LLM生成token流 → 累积到句子边界 → TTS合成 → 音频chunk下发 → 客户端播放

流程：
1. LLM开始流式输出 "哎哟这脚！"
2. 检测到句号/感叹号，触发TTS
3. TTS边合成边推流到客户端
4. 客户端收到第一个音频chunk即开始播放
5. 同时LLM继续生成下一句
```

**优势**：用户感知延迟 = max(TTS首包, LLM第一句生成)，而非两者之和。

---

## 6. 音频格式

| 参数 | 值 |
|------|-----|
| 编码 | PCM 16bit |
| 采样率 | 24kHz |
| 声道 | 单声道 |
| 传输 | WebSocket 二进制帧 |

---

## 7. 音频缓存策略

对于高频固定内容（如比赛开始问候"嗨～比赛开始了！一起看吧～"），预生成音频并缓存：

```python
cache_key = f"tts:{voice_id}:{text_hash}"
# 命中缓存 → 直接返回音频文件URL
# 未命中 → 合成 → 存储 → 返回
```

缓存内容：
- 比赛开始/结束语
- 常见短语（"好球！""哇！""哎..."）
- 用户偏好问候语

---

## 8. 降级方案

| 场景 | 策略 |
|------|------|
| TTS API超时 | 切换到本地 CosyVoice 2 |
| 完全不可用 | 通知用户"球球嗓子哑了，稍等一下～" + 仅文字气泡 |
| TTS质量差 | 切换备选引擎 |
| 音频下载慢 | 降低码率（24kHz → 16kHz） |

---

## 9. 接口定义

```
输入：
POST /api/v1/tts/synthesize
{
  "text": "哎哟这脚！差一点点就进了！",
  "voice_id": "qiuqiu_v1",
  "emotion": "excited",
  "stream": true
}

输出（流式）：
WS Binary Frame: <PCM音频数据块>
WS Text Frame:   { "type": "tts_end", "duration_ms": 1200 }
```

## 10. 验证标准

- [ ] 首包延迟 P50 < 500ms, P95 < 800ms
- [ ] 音色盲评通过率 > 70%（"听起来像真人"）
- [ ] 情绪区分度：兴奋/平静/遗憾可感知区分
- [ ] 流式播放不卡顿、不爆音
