## 执行哲学

- **单人+CC，无沟通成本，无任务依赖**——可以按最优顺序串行推进
- **每个Phase结束是闸门日**：通过 = 继续，失败 = 触发回退
- **Phase 0 的3个验证结果决定整个计划走向**
- **CC的加速效应**：样板代码10-15x、集成5-8x、调试3-5x、学习SDK 1.5-2x
- **关键约束**：不是代码写多快，而是等API响应/App审核/踩SDK坑这些0x环节

## Phase 1：MVP核心（5/13-5/21，7天）

> CC高效应区。事件引擎、LLM管线、TTS管线都是样板代码密集区。

### Day 3-4（5/13-14）：事件管线
- **目标**：Mock数据源 → 事件引擎 → LLM → TTS → 音频文件，这条线跑通
- CC写：事件处理引擎（去重/节流/优先级）、Mock数据源、NATS消息封装
- 人工：LLM System Prompt v1.0 编写、TTS API选择确认

### Day 5-6（5/15-16）：陪看主流程
- **目标**：WebSocket通信层 + 客户端音频播放连通
- CC写：Go WebSocket服务端、Flutter WebSocket客户端、音频PCM播放
- CC写：人设Prompt模板（5种事件类型×3种情绪各2个句式）
- 验证：Mock事件 → 手机听到球球说话

### Day 7-8（5/17-18）：Live2D + 情绪TTS
- **目标**：角色展示 + 情绪化语音
- CC写：Live2D集成代码、嘴型同步、3个基础表情
- CC写：TTS情绪参数切换（兴奋/低沉/正常）
- 验证：进球事件 → Live2D兴奋表情 + TTS兴奋音色

### Day 9（5/19）：扩展功能日
- CC写：用户偏好存储（主队+昵称 → LocalStorage → 注入LLM上下文）
- CC写：极简身份设置页（选择主队+输入昵称）
- 验证：设置皇马为主队 → 皇马进球时用"我们"

### Day 10（5/20）：分享卡片 + 集成
- CC写：金句+角色形象 → 分享图生成
- 全链路集成测试

### Day 11（5/21）：Phase 1收尾
- Mock数据源回放90分钟比赛，全链路跑通
- 延迟测量：p50/p95/p99
- **闸门**：端到端 < 2s → 继续

## Phase 2：交互增强（5/22-5/28，5天）

### Day 12-13（5/22-23）：ASR语音输入
- **目标**：用户按住说话 → ASR转写 → LLM回复
- CC写：Flutter录音模块、WebSocket流式上传PCM
- CC写：ASR API对接（Whisper/SenseVoice）
- 验证：说"现在比分多少" → 球球回复当前比分

### Day 14（5/24）：打断机制
- **目标**：球球说话中 → 用户开始说话 → 球球静音
- CC写：音频混合策略（ducking衰减）+ 中断逻辑
- 验证：球球说话中按住麦克风 → 球球静音 < 300ms

### Day 15（5/25）：话痨调节
- **目标**：安静/标准/活跃三档
- CC写：档位切换UI + 事件节流参数调整
- 验证：安静档2分钟说话1次，活跃档30秒1次

### Day 16（5/26）：表情动作系统
- **目标**：进球兴奋/射门紧张/失误吐槽等核心表情
- CC写：事件→表情映射表 + Live2D表情切换
- 验证：进球 → 兴奋 < 100ms / 失球 → 遗憾

### Day 17（5/27）：名人语音彩蛋（条件性）
- **前置条件**：授权已获取
- CC写：音色切换UI + 独立TTS配置
- 未获取授权 → 跳过，标记feature flag

### Day 18（5/28）：Phase 2集成 + 闸门
- 全链路+ASR+打断集成测试
- **闸门**：用户提问→回复 < 3s，打断 < 300ms → 继续

## Phase 3：体验打磨（5/29-6/5，4天）

### Day 19-20（5/29-30）：性能优化
- **目标**：p95总延迟 < 2s
- LLM prompt精简（token预算从810→600）
- TTS预连接（keep-alive减少握手延迟）
- 事件管道批量处理优化
- CC写：延迟CI门禁脚本（超限PR阻断）

### Day 21（6/1）：内容去重 + 异常处理
- 句式池+相似度检测上线
- 5个错误处理GAP全部到位（见文档09第6.4-6.8节）
- LLM/TTS fallback测试

### Day 22（6/2-6/3）：内测准备 + 混沌实验
- 90分钟耐久测试 ×3轮 → 0崩溃
- 混沌实验 ×6场景 → 全部降级正常
- 真实比赛测试（找一场直播）

### Day 23-24（6/4-6/5）：内测反馈 + 收尾
- 找5-10人内测一场比赛
- 收集NPS初评 + Top 5问题
- **闸门**：NPS > 30（初评），延迟p95 < 2s，崩溃率 < 1%

## CC使用策略

| 任务类型 | 策略 |
|---------|------|
| 样板代码（CRUD/API client/配置） | CC全权生成，人工review |

| Prompt工程 | 人工设计，CC辅助变体生成 |
