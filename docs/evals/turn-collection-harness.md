# smart-turn v3.2 采集/标注/对比工具链方案(openspec/changes/smart-turn-v32 6.1-6.2 前置)

> 本档是工具链的**设计与验收方案**;三件工具的落地=下一轮 implement。
> 采样这一步无法替代:合成语音(TTS)的停顿与语速分布对「说完没」判断有
> 系统性域差,拿合成样本过门=自欺(ADR-0023:可感结论必须来自真实采集)。

## 一、目标与判据(直接引 spec Success Criteria)

- 评测集 ≥200 样本、三类覆盖:观赛激动语速 ≥60、平静闲聊 ≥80、犹豫停顿 ≥60;
- 两模型(现役 396MB pipecat smart-turn vs v3.2 8MB int8)同集离线对比,
  判据:说完点准确率不低于现役、抢话误判率(把没说完判完)不高于现役;
- 标注格式对齐既有 harness(client/tool/turn_cases.dart 的 A=句中停顿/
  B=句尾收束/C=噪声拖音三分类已验证,真实样本沿用同一判据面并扩展
  「激动/平静/犹豫」为采集场景标签)。

## 二、三件工具设计

### T1 采集 — client/tool/turn_collection.html(纯静态页,零依赖)

- **流程**:提示语卡片流(内置 200+ 条中文提示,按三场景分组:激动的进球
  反应/平静的战术闲聊/犹豫的半截话)→ 点「开始」对着麦克风念 → 停止即
  存档,自动命名 `turn_{场景}_{序号}.wav` + 伴生元数据 JSON(提示语 ID/
  采样率/时长/设备);
- **录音**:MediaRecorder(AudioWorklet 采集,本机采样率原样保存,后处理
  统一转 16kHz PCM——**16kHz 不符会静默误判,是 spec 点名的坑用例**,
  统一转码在 T3 的前处理做,采集端不冒险);
- **防作弊面**:每条录音长度合理性校验(<1s/>30s 标记重录)、同一提示语
  不可重复提交;
- 产出目录约定:`turn_dataset/raw/*.wav + *.json`(gitignored,数据不入库)。

### T2 标注 — client/tool/turn_annotation.html(纯静态页,零依赖)

- **流程**:逐条加载 raw 音频 → 波形图渲染 → 空格键播放/暂停 + 拖动游标
  标「说完点」→ 选类别(激动/平静/犹豫)→ 下一条;支持改判;
- **产出**:`turn_dataset/labels.jsonl`,每行一标:
  ```json
  {"file":"turn_excited_042.wav","speechEndMs":2340,"category":"excited",
   "annotator":"","annotatedAt":"2026-10-07T12:00:00Z","revised":false}
  ```
- **质量门**:单人全标后抽 10% 二次复标,标注一致性(说完点差 ≤250ms)
  ≥90% 才进对比——不达标先校准标注尺度再全量。

### T3 离线对比 — client/tool/turn_model_compare.mjs(node,零新增依赖)

- **前处理**:raw → 16kHz 单声道 s16le PCM(统一转码,采样率不符用例
  显式保留三条作坑验证);
- **评测**:每条样本切到标注说完点 + 完整音频,分别送两个 sidecar 端点
  (`turn_query` 协议同形,v3.2 以并行 sidecar 形态起本地端口),采集
  isComplete 判定与延迟;
- **指标**(对齐 spec 判据):
  - 说完点准确率:标注说完点后 `holdMs` 窗内判「说完」的比例;
  - 抢话误判率:标注未说完(句中停顿场景)却判「说完」的比例——**不高于
    现役才过门**;
  - 轮次延迟:说完点到判定的中位/p90;
- **产出**:`docs/evals/turn-v32-compare.md` 自动生成报告(两模型矩阵+
  分场景拆解+坑用例结果),人工复核后落库。

## 三、流程与工作量(用户侧)

1. 开两个 T1/T2 静态页(本地 file:// 即可,无需服务);
2. 对麦克风念:200 条 × 均 8 秒 ≈ 27 分钟纯录音(加休息约 1 小时);
3. 标注:200 条 × 均 15 秒 ≈ 1 小时(含复标抽检 20 分钟);
4. 跑 T3 一条命令出对比报告 → 过门走 6.4a 切换,不过门走 6.4b 冻结记录。

## 四、验收(工具落地时的判据)

- [ ] T1:采集 5 条真实录音,16k 转码无损、元数据完整;
- [ ] T2:标注 5 条,labels.jsonl 字段与格式符合本档;复标一致性流程跑通;
- [ ] T3:对现役 sidecar 离线评测 5 条合成用例(turn_cases.dart 同源),
      指标输出与既有 harness 结论一致(回归锚);
- [ ] 全量 200 样本产出后:T3 报告落库,门判(6.4a/6.4b)定夺。
