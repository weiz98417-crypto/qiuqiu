# 0014 · 球球全套资料解冻与逐篇重写（修订 ADR-0004 决定 3）

## 背景

ADR-0004 将同批生成、零代码锚点的全套资料（`docs/球球全套资料/`，89 个 md）整体冻结，并规定后续内容工作在 `docs/球球课程/` 进行（决定 3）。冻结四天来项目完成了 ADR-0005~0013（表达唯一合同、记忆 seam、表演映射、运营台身份与 JWT、意图路由、openaicompat、operator.html 退役）等一串架构变更，旧文与现行系统已大范围脱节；且"安静 / 退出 / 交回给用户"这套控制契约在 40+ 篇里以不同措辞各述一遍（单篇命中 30–80 次），文档无法局部修订。所有者于 2026-09-20 拍板：这套资料的产品叙事价值值得重写投入，解冻逐篇重写。

## 决定

1. **解冻、原地重写**：`docs/球球全套资料/` 恢复为活跃文档；索引冻结横幅由 v2 重写说明取代。冻结版本由 git 历史（`be1c94d`）永久可回溯，不设旧版目录并存。
2. **结构保留**：九卷目录与文件编号不动。理念去重、概念单一归属、术语统一全部作为内容改动逐篇落实；结构级手术（合卷、卷5 处置）留待对应卷的简报阶段单独拍板。
3. **宪法合规**：每篇按 `docs/reviews/产品设计审查标准.md`（ADR-0004）重写——设计/工程类主张带四态 status 锚与章末主张-锚点表（每章 ≥5 仓库锚点、无锚段落 ≤30%）；市场/战略/合规类章节按 A–D 证据分级标注，不强加代码锚点。
4. **编排与流程**：每卷一个调研子代理（逐篇诊断 + 内部代码锚点取证 + 按卷别外部查证：卷1/2/6 必查、卷3/7 轻查、其余纯内部）→ 所有者逐卷拍板改动简报（讨论单位是卷，不是篇）→ 拍板一卷即派工：卷内每篇一个重写子代理并行执行，另设宪法审查代理逐篇验收（每章 ≥5 锚点、无锚段落 ≤30%、status 四态齐全）。纯机械错误（编号断层、死引用）顺手修复，不单独立报。卷0 由所有者与主代理直接讨论开篇；卷5 调研先行、处置方式在抵达该卷时单独拍板。
5. **口径**：对外可读；术语用 CONTEXT.md 统一语言（中文为主、英文括注），遗留概念（安静→主动沉默、退出/离开权→干预级别、交回→ReturnMode 等）在重写中替换，并在索引处保留一张映射表。不写成本、定价与运营敏感细节。
6. **与球球课程的关系**：本决定不改动 `docs/球球课程/`；两者分工问题显式搁置，待全套重写完成后另行决定。

## 被否决的替代方案

- **维持冻结、只做路标化**（横幅全覆盖 + 新旧概念映射表）：能止住误导面，但所有者判断叙事价值值得重写，且冻结状态下内容只会与系统越离越远。
- **旧版移入子目录或另起新目录**：新旧两套并存会重新制造导航混乱——冻结前该目录的主要危害正是检索污染；git 历史已足够承担"旧版可回溯"。

## 后果

- ADR-0004 决定 3 中"后续内容工作在 `docs/球球课程/`"修订为：全套资料 v2 重写同样是现行内容工作；课程本身未动，其定位问题后置。
- 未来架构评审不得再把"冻结"当作现行决定引用；引用该目录状态时以本 ADR 为准。
- 卷5（描述从未存在服务的 20 篇工程实践卷；其中 47/56/57 三篇已被球球课程同源重写覆盖）如何处置是本决定的显式遗留问题，抵达该卷时须单独拍板。

## 修订（2026-09-20）：体例两轨制

所有者确定本资料集的用途为**对外宣传与产品教学**，要求以顺向产品叙事呈现、不暴露逆推重构痕迹（叙事顺序属正常案例包装）。据此修订决定 3 与 5：

- **两轨分工**：本资料集 = 对外叙事集（正常产品文档体例）；`docs/球球课程/` = 内部事实源（status 锚范式不变）。能力事实以课程与代码为准，两轨不得矛盾。
- **对外叙事集体例**：不携带 status 锚、主张-锚点表、A-D 分级术语与重写工程痕迹（双日期、结算注、证据债、现实对齐框、初版对照表、差距登记）；未实现能力仅以路线/规划语气出现；能力宣称必须与真实实现一致；不虚构用户研究数据、试点战报、团队名单与增长数字。
- **结算层归档**：对外化时剥除的结算层内容（原件）归档于 `docs/球球课程/notes/`，供内部与课程引用，不随对外版分发。
- **宪法审查范围收窄**：对本资料集只审能力宣称真实性、禁词与事实一致性；锚点表形式不再要求（它是内部事实源的形式要求）。
- **一条不变的红线**：叙事顺序可包装，事实性断言不造假——这也是对外合规的要求（本集 02 篇所述标识与广告义务同样约束本集自身的能力宣称）。
