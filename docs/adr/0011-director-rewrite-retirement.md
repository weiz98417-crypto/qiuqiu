# 0011 · 实战导演页重构与 operator.html 退役路径

## 背景

`operator.html`（4,076 行零构建单文件）中除 `#live` 实战导演外的四个标签已迁入 React 运营台；`#live` 承载最重的实时运营面：18 事件草稿模型、事实时间线、语音草稿流、手动话术三通道、比分更正。28 个 operator-control eval 全部测它——既是安全网也是回归风险清单。

## 决定

1. **四步重写**（每步独立合并）：事件模型移植 → 草稿卡组件化 → 语音草稿流 → 事实时间线；新页位于 `/console/match/:id/director`，以"新版实战导演"链接并存，不替换。
2. **退役标准（硬性）**：28 evals 全绿 + 功能对齐清单逐项签署 + 导演（用户）真机验收——三样齐后才删 `operator.html`。
3. **请求形状冻结**：全部幂等写调用与既有端点原样保留，eval 断言的请求形状是回归基线。

## 被否决的替代方案

- **一步到位整页重写替换**：导演在比赛进行中实时使用旧页，重写期间不可用即事故。
- **继续维护 operator.html**：4 千行零构建单文件的每次修改都是高风险手术；新台组件化后旧页自然退役。

## 后果

- 过渡期两代并存（新台导航挂 `#live` 外链），退役后 `operator.html` 全删。
- 事件模型以快照测试锁定（operator-live-state.js ↔ event-model.ts byte-shape 对比），防移植漂移。
