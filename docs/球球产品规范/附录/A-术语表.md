## 4. 词汇处置速查（禁用与替代）

以下措辞是宪法错误时代沉淀的「克制期遗产」，不得随迁移进入本规范；评审按左列词汇 grep，命中即改。

| 遗产措辞 | 判定 | v3 处置 |
| --- | --- | --- |
| 「克制」作为产品身份/原则词 | 人格遗产 | **禁用**；仅可在描述具体频控参数时使用（如「发言间隔下限」） |
| 「安静档」 | 人格遗产+代码键名混杂 | 叙述统一改「**低频档**」；`quiet` 仅作为设置键技术标签出现在括号内 |
| 「主动沉默」「沉默的语义」专节 | 人格遗产 | **撤销专节叙事**；不发言一律写为「调度器的输出结果之一」（触发条件/时长/退出条件见 07 篇），不赋予沉默人格语义 |
| 「退出/离开」作为关系叙事（「球球会适时退出对话」类） | 宪法错误核心遗产 | **禁用**；「退出」仅两种合法语境：a) 应用/会话退出（工程）；b) 《拟人化办法》第十九条「便捷退出途径」（合规能力条款，落 05/12 篇） |
| 「不打扰是陪伴的一部分」类格言 | 人格遗产 | 禁用；低频行为的理由一律写工程依据（门禁条件/频控参数/用户设置） |
| 「用户控制优先：安静档等客户端控制压过生成、播放」 | 半遗产 | 原则保留但改写：「**用户设置优先**：用户设置压过默认生成策略（三档频控/干预级别/删除）」，不点名「安静」 |
| 正典 Avoid 词族（AI 助手/虚拟女友/游客模式/补句/情绪标签/RAG dump 等） | 正典反例 | 各词条 Avoid 列的混用词不进入正文；全表见 CONTEXT.md 各词条 |
| 法规条款：2h 提醒、依赖预警、便捷退出、未成年人模式 | **不是遗产，是硬要求** | 全部保留，按能力条款写进 05/12/33 篇，标注法规依据与待建状态 |

## 设计说明（写法依据，非词条）

1. **镜像而非重写**：§1 的 36 词条定义按 CONTEXT.md 原义压缩为中文单句，不引入正典没有的语义；Avoid 反例不复制（正典已有），只在纪律第 4 条给入口。
2. **首现篇口径**：指词条在 42 篇活规范中获得正典定义的承接篇（ topical home），不是全文检索的首次出现位置——跨篇早现不改变承接关系。
3. **v2 附录 A 的处置**：v2 附录A「三十个术语」在其定稿当日即脱锚 1 个、至基线脱锚 6 个（实测）；v3 以「镜像正典」结构根治计数漂移——正典增删是唯一变更入口。
4. **与 PRD 8.2 的分工**：PRD 第八章 8.2 是 36 词条的精简索引（需求侧入口）；本表是规范侧唯一术语面，两处与 CONTEXT.md 冲突时先修正典、再同步两处镜像。
